## Основной код

Функция подсказок из игры «Угадай число» — switch с сопоставлением диапазонов:

```csharp
string GetHint(int difference)
{
    switch (difference)
    {
        case <= 3:  return "Горячо!";
        case <= 10: return "Тепло";
        case <= 25: return "Прохладно";
        default:    return "Холодно!";
    }
}
```

Логика допуска к экзамену на логических операторах:

```csharp
bool goodAttendance = attendance >= 14;
bool goodGrades = practiceGpa >= 3.0;
if (goodAttendance && goodGrades)
    Console.WriteLine("+ Допуск к экзамену разрешён.");
else if (!goodAttendance && goodGrades)
    Console.WriteLine("- Недостаточкно посещений. Нужно отработать пропуски.");
```

## Таблица конструкций

| Конструкция | Когда используется |
|---|---|
| if | Одно условие, один блок действий |
| if / else | Два взаимоисключающих варианта |
| else if | Проверка нескольких условий по очереди |
| switch / case | Одно значение сравнивается с набором констант |
| ?: | Присвоить одно из двух значений в одну строку |
| && | Оба условия должны быть истинны |
| \|\| | Достаточно одного истинного условия |
| ! | Инверсия условия |
| int.TryParse | Ввод числа от пользователя без падения программы |

## Ответы на вопросы

1. **Зачем int.TryParse вместо int.Parse?**  
   `Parse` при нечисловом вводе выбрасывает исключение и программа падает. `TryParse` возвращает `false` и даёт проверить ввод, поэтому в играх и меню используем его.

2. **Когда switch удобнее if/else if?**  
   Когда одно и то же значение сравнивается с конкретными константами (номер пункта меню, символ операции, номер месяца). Для диапазонов и сложной логики — if/else if.

3. **Что будет без break в switch?**  
   Выполнение «проваливается» в следующий case без проверки условия. В C# после case с кодом нужен break, иначе ошибка компиляции.

4. **= и == — в чём разница?**  
   `=` присваивает, `==` сравнивает. Если написать `if (x = 5)`, это присвоит 5 и условие всегда истинно.

5. **Когда применять тернарный оператор?**  
   Когда в одну строку нужно выбрать одно из двух коротких значений. Для нескольких действий — обычный if/else, так читается лучше.
